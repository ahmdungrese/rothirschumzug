# Design Vision & Guidelines

## 1. Core Vision
The goal is to create a completely new, state-of-the-art, and breathtaking User Interface (UI) and User Experience (UX) for this application. 
Currently, the application has no predefined CSS or styling attached to it. The AI has complete creative freedom to redesign the entire application from scratch based purely on the data and logic provided.

## 2. Aesthetic Requirements
- **Premium & Modern**: The app must feel expensive, professional, and highly polished.
- **Clean & Minimalist**: Avoid clutter. Use ample whitespace (negative space) to let the content breathe.
- **Glassmorphism & Depth**: Utilize subtle blurring, translucent backgrounds, and soft shadows to create depth and a modern feel.
- **Animations**: Incorporate micro-animations for interactions (hover states, button clicks, page transitions) to make the app feel alive and responsive.

## 3. Color Palette & Typography
- **Colors**: Do not use generic colors. Create a highly curated, harmonious color palette. You can derive the primary color from the uploaded company logo (Rothirsch), but elevate it with sleek dark modes or bright, vibrant gradients.
- **Typography**: Use modern, highly readable web fonts (e.g., Inter, Roboto, Outfit, or Plus Jakarta Sans). Ensure excellent hierarchy through font weights and sizes.

## 4. Components & Layouts
- **Layout**: The main layouts (Sidebar, Header, Dashboard) must be fully responsive.
- **Cards & Data**: Display data in beautiful, rounded cards. Use modern data tables with sticky headers, subtle row hover effects, and clear status badges.
- **Navigation**: Make navigation intuitive but visually striking.

## 5. Instructions for the AI
1. **Analyze Logic**: Look at the provided `src/app/`, `src/lib/`, and `src/context/` files to understand what the app does.
2. **Do Not Ask for Existing CSS**: There is no existing CSS. You are the sole designer.
3. **Generate Styling**: Provide the implementation using modern Tailwind CSS or sleek Vanilla CSS. 
4. **Focus on WOW-Factor**: If the design looks basic or like a simple MVP, it is not good enough. Push the boundaries of modern web design.
